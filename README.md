# Decoded: True Stories (formerly Riddle & Ruckus)

Story cryptograms: true stories (builders, inventors) and real brain science told in secret code, each ending with a life lesson, one chapter per puzzle.
Sister app to Mischief & Motive (Sild Growth OÜ). Free stories + one-time unlock, no ads.

Edit `stories.js` / `app.html`, then `python3 build.py && OUT=. python3 pwa.py`.
